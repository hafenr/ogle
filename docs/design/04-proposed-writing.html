Usage

sh
ogle README.md

Or use File › Open… (⌘O), drop a file on the Dock icon, or pick Ogle from Finder’s “Open With”.

Layout

  • Sources/Ogle – the AppKit app: window with sidebar, WKWebView preview, FSEvents file watcher, cmark-gfm rendering, and the editor pane.
  • Resources/ogle.lua – loaded into the editor’s Neovim; reports its scroll position, unsaved changes and background color to Ogle over a Unix socket.
